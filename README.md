# Algorithms & Problem-Solving – Level 2 (Solutions)

This repository contains my solutions to **50 programming problems** from the Algorithms & Problem-Solving – Level 2 (Course 5), instructed by Dr. Mohamed Abu-Hadhoud on Programming Advices.

This course builds upon the foundations established in Level 1 and focuses on gaining practical programming experience through solving more challenging problems, learning from professional solutions, and continuously improving problem-solving skills.

## Course Objectives

- Solving more complex algorithmic problems.
- Strengthening logical and analytical thinking.
- Improving problem-solving speed and confidence.
- Learning new ideas and approaches from professional solutions.
- Recognizing common problem-solving patterns.
- Applying Clean Code principles and Divide and Conquer.
- Building practical programming experience through continuous practice.
- Transitioning from problem-solving exercises to real programming projects.

## Learning Approach

The course follows a practice-driven learning approach:

1. Attempt to solve each problem independently.
2. Review the professional solution.
3. Understand new ideas and approaches.
4. Learn from mistakes and improve problem-solving skills.

## Repository Contents

- 50 C++ programming problems and their solutions.
- Practical exercises designed to strengthen algorithmic thinking.
- Different problem-solving approaches and techniques.
